# Lawal Usman | Websites for Roofers

A bright, fast, mobile-first website for a web designer who builds sites for Australian roofing and roof restoration businesses.

Built with plain HTML, CSS and JavaScript. No build step or dependencies.

## Pages

- `index.html` Home
- `about.html` About
- `services.html` Services
- `approach.html` Our Approach
- `contact.html` Contact (Netlify Forms)
- `thanks.html` Form thank-you page
- `404.html` Not-found page

## Run locally

Open `index.html` in your browser.

## Deploy

1. Push this repository to GitHub.
2. In Netlify choose **Add new site > Import from Git** and pick this repository.
3. Leave the build command empty and set the publish directory to `/`.
4. In Netlify, open **Forms > Notifications** to get contact-form emails.

## Customising

- Add your photo as `images/lawal.jpg` (shown on the About page).
- Prices are in the pricing cards on `index.html`.
